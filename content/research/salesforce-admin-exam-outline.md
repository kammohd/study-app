# Salesforce Certified Platform Administrator: exam outline

Source: Salesforce Help, "Salesforce Certified Platform Administrator Exam Guide" (https://help.salesforce.com/s/articleView?id=005298966). Read 2026-10-26. Questions align to **Summer '25**; the weightings were updated in 2026, so re-check the guide before booking.

## Format
- 60 multiple-choice questions plus up to 5 unscored; 105 minutes
- Passing score 68% (English)
- US$200, retake US$100; no prerequisite; 6+ months admin experience recommended
- Proctored onsite or online; no reference materials
- Recommended: Trailmix "Prepare for Your Salesforce Platform Administrator Certification", Superbadges "Object Relationships" and "Flow Administration", Trailhead Academy CRT101 and ADX201

## Objectives (abridged)
1. **Configuration and Setup:** company settings; declarative UI config (app menu, list views, global actions, Lightning App Builder); user setup and licences; org security controls (identity verification, Setup Audit Trail, login hours, session settings); the sharing model (OWD, role hierarchy, teams, public groups, report and dashboard folders); profiles vs permission sets, permission set groups, muting.
2. **Object Manager and Lightning App Builder:** standard object architecture and relationships (master-detail, lookup, junction, record types, Schema Builder); fields and page layouts, including what deleting a field affects (roll-ups, cross-object formulas, picklist dependencies); assigning layouts, Lightning page visibility, record types, business processes, quick actions.
3. **Sales and Marketing:** sales process (leads, opportunities, Path); opportunity tools (forecasting, territory management, Einstein for Sales); lead automation and campaigns (lead convert, assignment rules, campaign members).
4. **Service and Support:** case management (assignment rules, queues); automation (support process, auto-response, escalation, Einstein for Service).
5. **Productivity and Collaboration:** activities (tasks, events); Chatter groups; Salesforce mobile app; AppExchange (managed vs unmanaged packages).
6. **Data and Analytics:** importing, updating, transferring, mass deleting, exporting, backups (Data Import Wizard, data loader); data validation (duplicate and matching rules, validation rules); reports and report types (joins, buckets, formulas); report visibility under the sharing model; dashboards (widgets, dynamic dashboards, view as, filters, refresh).
7. **Automation:** choosing the right tool (escalation, assignment rules, default automation user); Flow (screen, record-triggered, autolaunched, order of execution); approval processes.
8. **Agentforce:** capabilities and use cases (when AI is appropriate, security, agent permissions); maintaining prompts and instructions in Agent Builder.
